# /cluster_summaries — Sensor Behavior Across Clusters

This folder contains summarized cluster-wise sensor statistics for each dataset (FD001–FD004) produced in Phase 2 of the project. These summaries provide an overview of how each sensor's behavior varies across the five degradation stages generated by KMeans clustering.

---

## Files

| File | Description |
|------|-------------|
| [`FD001_ClusterSummary.csv`](./FD001_ClusterSummary.csv) | Average values of all sensors and cycle time for each KMeans cluster (Stage 0 to Stage 4) in FD001 |
| [`FD002_ClusterSummary.csv`](./FD002_ClusterSummary.csv) | Cluster summary for FD002 |
| [`FD003_ClusterSummary.csv`](./FD003_ClusterSummary.csv) | Cluster summary for FD003 |
| [`FD004_ClusterSummary.csv`](./FD004_ClusterSummary.csv) | Cluster summary for FD004 |

Each file includes:
- Mean values of all retained sensor columns
- Average cycle (`time`) per cluster stage

---

## Purpose and Use

These summaries are used to:

- Analyze how sensor readings change over the course of engine degradation.
- Determine which sensors correlate with progression through degradation stages.
- Provide stage-wise context for classification labels (Phase 3) and RUL regression targets (Phase 4).

They help validate whether the clustering output is meaningful in terms of actual physical degradation patterns.

---

## Example Interpretation

In `FD001_ClusterSummary.csv`, both `sensor_11` and `sensor_12` show a downward trend from Stage 0 to Stage 4. This pattern aligns with expected degradation behavior and suggests that these sensors are strong candidates for feature selection in supervised learning tasks.
