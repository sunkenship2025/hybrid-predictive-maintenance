# 📁 /report — Evaluation and Cluster Insights

This folder contains **quantitative summaries** and **high-level insights** derived from clustering.

---

## 📦 Contents

| File | Description |
|------|-------------|
| `silhouette_scores.json` | Silhouette scores for each dataset using both KMeans and Agglomerative methods |
| `top_variance_sensors.json` | Top 5 sensors with highest variance per dataset (useful for feature selection) |
| `contributors.txt` | Team contributor names (optional for collaboration or submission) |
| `cluster_summaries/` | Folder with CSV files showing sensor averages per stage |

These reports support:
- 🔍 Cluster evaluation
- 📈 Report writing
- 🧠 Model interpretability
